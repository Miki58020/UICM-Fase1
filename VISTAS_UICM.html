Acceso al sistema
URL Descripción
/login

Login institucional. Formulario de acceso con correo y contraseña. Incluye modal de recuperación de contraseña (Alpine.js).

Público
/dashboard

Panel principal. Accesos rápidos a todos los módulos del sistema agrupados en cards.

Requiere login
Proceso de admisión
URL Descripción
/

Página de inicio. Portal institucional público. Presentación de la universidad e inicio del proceso de admisión.

Público
/registro

Registro de aspirante. Formulario completo con datos personales y académicos para solicitar ingreso. Al enviarlo se genera un folio único.

Público
/confirmacion

Confirmación de registro. Pantalla de éxito tras enviar el formulario. Muestra el número de folio asignado al aspirante.

Público
/seguimiento

Seguimiento de solicitud. El aspirante ingresa su folio para consultar el estado actual de su solicitud de ingreso.

Público
/resultado

Estado de inscripción. Muestra una línea de tiempo de 5 pasos (Solicitud enviada → Datos validados → Pago pendiente → Pago en revisión → Inscripción completada) con el paso actual resaltado. Si el estado es "Pago pendiente" aparece el botón "Realizar pago".

Público
/aspirante/pago

Pago de inscripción — MercadoPago. Muestra los datos del aspirante (folio, programa, monto) y el Payment Brick de MercadoPago embebido para pagar en línea (tarjeta, SPEI, efectivo). Ya no se sube comprobante manual.

Público
/aspirante/pago/retornoGET

Retorno desde MercadoPago. URL de retorno tras completar el pago en el brick. El sistema evalúa el parámetro status de MP y redirige a la pantalla de confirmación correspondiente.

Público
/aspirante/pago-confirmacion

Confirmación del pago. Pantalla final con tres estados posibles: Pago confirmado (verde, inscripción en proceso), Pago en revisión (naranja, MP aún procesando) o Pago rechazado (gris, puede reintentar).

Público
Portal del alumno
URL Descripción
/alumno

Panel personal del alumno. Muestra saludo de bienvenida, cards con matrícula, programa, grupo, cuatrimestre y estado administrativo. Tabla de materias (clave, profesor, horario, aula, créditos) e historial de pagos con estados Pagado / Pendiente.

Alumno
/alumno/comprobante/{pago}

Comprobante de pago. Muestra el detalle del pago seleccionado: concepto, monto, período, fecha y estado. Accesible desde el historial de pagos del portal del alumno.

Alumno
Control Escolar — Administración
URL Descripción
/admin/aspirantes

Validación de aspirantes. Lista de todos los aspirantes registrados con contadores (pendientes / validados / rechazados), badges de estado y botones de acción: Ver detalle, Aprobar, Rechazar.

Admin / Control Escolar
/admin/aspirantes/show

Ficha del aspirante. Datos personales completos del aspirante, lista de documentos entregados (subido / pendiente) con contador de documentos recibidos. Botones: Aprobar, Rechazar.

Admin / Control Escolar
/admin/inscripciones

Generación de matrículas. Lista de aspirantes con pago validado listos para inscripción. Contadores de estatus y botón "Generar matrícula" por registro.

Admin / Control Escolar
/admin/inscripciones/{alumno}/resultado

Confirmación de inscripción. Muestra la matrícula generada (ej. UICM-2026-IS-001), el grupo asignado y las credenciales de acceso (correo institucional y contraseña temporal) del nuevo alumno.

Admin / Control Escolar
/admin/alumnos

Listado de alumnos activos. Tabla de alumnos inscritos con matrícula, nombre, programa, grupo, cuatrimestre y estado. Permite editar grupo y estado directamente desde la tabla.

Admin / Control Escolar
/admin/solicitudes-contrasena

Solicitudes de contraseña. Listado de solicitudes de reseteo de contraseña enviadas por alumnos. Control Escolar puede atender cada solicitud y enviar la nueva contraseña por correo.

Admin / Control Escolar
Finanzas
URL Descripción
/finanzas/pagos

Lista de pagos. Tabla de pagos registrados vía MercadoPago con folio del aspirante, nombre, programa, monto, fecha y estado (Pendiente / Validado / Rechazado). Los pagos llegan automáticamente al confirmarse por el webhook de MP.

Finanzas
/finanzas/pagos/{id}

Detalle del pago. Datos completos del pago: aspirante, concepto, monto, ID de pago de MercadoPago y estado actual. Botones: Aprobar pago (verde), Rechazar pago (gris).

Finanzas
Coordinación Académica
URL Descripción
/admin/materias

Gestión de materias. Catálogo de materias con clave, nombre, programa, cuatrimestre y estado (activa/inactiva). Modal Alpine.js para crear o editar. Botones de activar/desactivar por registro.

Coordinación Académica
/admin/profesores

Gestión de profesores. Planta docente registrada con ID, nombre, correo institucional, teléfono, especialidad y estado. Modal para agregar o editar. Botones de activar/desactivar.

Coordinación Académica
/admin/carga-academica

Generación de carga académica. Filtros por ciclo, cuatrimestre, programa y grupo. Al cargar: muestra resumen del grupo (alumnos, materias, profesores) y tabla de materias asignadas. Botón principal "Generar carga académica" con pantalla de éxito al finalizar.

Coordinación Académica
Administrador del sistema
URL Descripción
/admin/usuarios

Gestión de usuarios del sistema. Listado de todos los usuarios con rol, correo y estado. Permite crear nuevos usuarios administrativos (finanzas, coordinación, control escolar), editar datos y eliminar cuentas. Accesible solo para el rol admin.
